## Áttekintés
A SenseNet Project Installer átalakítása általános célú Plot Manager automatizációs keretrendszerré megfelelő dokumentációval, licenceléssel és arculattal.

<!-- documentation-anchors:start -->
<a id="doc-goals"></a>
<!-- documentation-anchors:end -->
## Célok
- A projekt átnevezése, hogy tükrözze valódi célját: általános automatizációs keretrendszer
- A licencelés egységesítése a vállalati bevezetéshez
- Átfogó dokumentáció létrehozása
- Stabil alap megteremtése a jövőbeli fejlesztéshez

<!-- documentation-anchors:start -->
<a id="doc-acceptance-criteria"></a>
<!-- documentation-anchors:end -->
## Elfogadási feltételek
- A projekt sikeresen "Plot Manager" névre átnevezve
- Az MIT-licenc következetesen alkalmazva minden komponensen
- A README teljesen átírva az automatizációs keretrendszer képességeinek megfelelően
- A dokumentáció rendbe téve és teljes egészében angol nyelvű
- Megvalósításkövetési rendszer létrehozva

<!-- documentation-anchors:start -->
<a id="doc-tasks"></a>
<!-- documentation-anchors:end -->
## Feladatok
- A projektstruktúra és architektúra elemzése
- A develop és master ágak összehasonlítása
- Feature ág létrehozása: feature/foundation-improvements
- A README átírása Plot Manager automatizációs keretrendszerként
- A licenc egységesítése MIT-re minden komponensben
- A docs/settings.md angolra fordítása és modernizálása
- A GUI package.json márkanevének frissítése "plot-manager-gui" értékre
- Az alapfejlesztések commitolása
- A projektáttekintés hivatkozásainak frissítése Plot Managerre
- Történetvezérelt fejlesztéskövetési rendszer létrehozása

<!-- documentation-anchors:start -->
<a id="doc-business-value"></a>

## Üzleti érték
- Világos projektidentitást teremt általános célú automatizációs eszközként
- Az MIT-licenc szélesebb vállalati bevezetést tesz lehetővé
- A professzionális dokumentáció javítja a használhatóságot és a betanulást
- Megalapozza a rendszeres funkciófejlesztést
