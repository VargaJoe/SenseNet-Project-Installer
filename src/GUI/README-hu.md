# SNOnlineInstaller

<!-- documentation-navigation -->
[English](README.md) | [Magyar](README-hu.md) · [Dokumentáció](../../docs/README-hu.md) · [Projekt](../../README-hu.md)
<!-- /documentation-navigation -->

Ezt a projektet az [Angular CLI](https://github.com/angular/angular-cli) 1.6.8 verziója generálta.

Ez a megőrzött történelmi Angular kliens. A jelenlegi közös asztali és
böngészős alkalmazáshoz a [kezelőfelület útmutatóját](../../docs/management-user-guide-hu.md)
és a [komponenstérképet](../../docs/migration-map-hu.md) használd.

## Fejlesztői kiszolgáló

A fejlesztői kiszolgálót az `ng serve` indítja. Nyisd meg a `http://localhost:4200/` címet. Ha módosítod valamelyik forrásfájlt, az alkalmazás automatikusan újratöltődik.

## Kódgenerálás

Komponens generálásához futtasd az `ng generate component component-name` parancsot. Az `ng generate directive|pipe|service|class|guard|interface|enum|module` is használható.

## Build

A projektet az `ng build` építi. Az eredmény a `dist/` könyvtárba kerül. Production buildhez a `-prod` kapcsolót használd.

## Unit tesztek futtatása

Az `ng test` a [Karma](https://karma-runner.github.io) segítségével futtatja a unit teszteket.
